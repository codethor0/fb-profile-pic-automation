# Code of conduct

This project is for people who want to make a small tool work well. To keep it useful for everyone:

- Be respectful. Disagree about code and ideas, not about people.
- No harassment, insults, discrimination or personal attacks.
- Do not post other people's private information, or screenshots of accounts that are not yours.
- Stay on topic in issues and pull requests.

Maintainers can edit, hide or remove comments, close issues and pull requests, and block people who break these rules.

To report a problem, use a private
[GitHub security advisory](https://github.com/codethor0/fb-profile-pic-automation/security/advisories/new)
and say it is a conduct report. Reports are handled in confidence.
